# advance42_dslr

## dev installation
- Start by install and run Virtual Environement:
```sh
	python3 -m venv venv
	source venv/bin/activate
	pip install -r requirements.txt
```
- Update dependency list for venv:
```sh
	pip freeze > requirements.txt
```
- Lint:
```sh
	flake8 src
```
- Venv:
```sh
	source venv/bin/activate
```
